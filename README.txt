GAGANDEEP & JASWINDER — WEDDING INVITATION WEBSITE

Files:
- index.html: page content and invitation details
- style.css: responsive styling and animations
- script.js: envelope opening, falling petals, scratch card, scroll reveal, countdown

Preview locally:
1. Keep all three files in the same folder.
2. Double-click index.html or open it in a browser.
3. Internet is needed for Google Fonts. All core interactions work without a build step.

Deploy:
- Cloudflare Pages: upload this folder as a static site, or connect a Git repository containing these files.
- Netlify: drag and drop the folder into the manual deploy area.

Notes:
